## 数学主线与依赖

| 主线 | 本轮完成与自查重点 |
|---|---|
| 商空间 | d²=0使Bᵏ包含于Zᵏ，商定义零类等价于全局恰当；负次数、超出维数及B⁰=0明确约定 |
| 零次 | 闭函数局部常值，按连通分支取直积而非有限支撑直和；可数离散空间给无限维例子 |
| 代数与拉回 | 外积更换代表元的差为恰当，分次交换；任意光滑映射均诱导反变代数同态，无单射/满秩要求 |
| 周期 | 只在紧无边有向测试流形上用Stokes检验类；一般顶次积分暂只证明下降，不偷用一般de Rham比较或Poincare对偶 |
| 光滑同伦 | 用第7章同伦算子证明两端拉回相同，单列零次；形变收缩给逆拉回，所有具体同伦有公式及开邻域延拓 |
| 短正合 | q(α,β)=α−β；用ρVγ在U延零及−ρUγ在V延零构造提升；延零光滑性由支集从属性保证，不要求γ在交叠边缘有界 |
| 连接映射 | 闭γ提升后微分可拼成全局闭η；逐项证明提升、代表元及单位分解选择无关性 |
| 长正合 | 在局部二元组、交叠、全局三类位置分别证明核等于像；零次单列，未以图追踪口号或外引补足核心步骤 |
| 圆周 | 周期函数一形式分解为平均值乘λ加dg；Mayer–Vietoris交叠两分支的矩阵秩一；连接类的周期按本书顺序为c₊−c₋ |
| 球面 | 两极交叠微分同胚于Sⁿ⁻¹×(−1,1)，给明确收缩；H⁰/H¹先计算，再归纳k≥2；S⁰单列为两点 |
| 积分归一化 | 先得Hⁿ(Sⁿ)一维，再用正体积形式的正积分证明积分同构，未倒置依赖；顶次生成元平方由维数为零，兼顾偶数n |
| 支集边界 | 普通上同调不要求紧支；一般拉回与同伦算子不保持紧支，习题计算Hc¹(R)=R而H¹(R)=0 |

依赖链：第6章外代数、第7章d/自然性/同伦算子与Poincare局部引理、第8章单位分解及紧支Stokes → 商空间与上同调运算 → 光滑同伦不变性 → 短正合及连接映射 → 长正合性 → 圆周与球面计算。未调用一般奇异上同调、连续同伦的光滑逼近、Kunneth或Poincare对偶来证明这些主线。

本章默认无边有限维光滑流形及实系数普通de Rham上同调；未声称所有流形上同调有限维。一般紧连通定向流形的顶次积分同构、de Rham比较定理和拓扑同伦不变性仍未证明。对圆周和球面的结论有各自完整计算，不据此扩展一般定理。
