## 数学主线与依赖

| 主线 | 完成内容与核查重点 |
|---|---|
| 单位分解 | 从第二可数与局部紧性得到可数预紧覆盖，递归构造内嵌紧耗尽；壳层有限选球、局部截断及归一化给可数紧支从属单位分解；逐点有限与局部有限明确区分 |
| 带边结构 | 半空间取最后坐标r≥0，光滑按局部欧氏延拓；延拓导数由内部稠密性唯一确定；换卡的逆导数排除边界映为内部，块矩阵最后对角元严格正 |
| 边界流形 | 由换卡限制得到无边的(n−1)维图册，继承Hausdorff性及第二可数性，包含为嵌入；切空间仍是完整n维空间 |
| 定向 | 基的正行列式等价类、局部连续选择与正体积形式判别；拼接正形式不发生抵消；一维带边卡单列符号，不错误要求所有卡都正向 |
| 边界符号 | 外向横截向量放首位，证明无关选择且无须度规；标准半空间自然边界坐标符号为(−1)^n；区间右正左负、圆环内外圈反向 |
| 积分 | 先定义单卡的带定向符号积分，区分形式行列式与欧氏换元的绝对行列式；双重单位分解证明选择无关性，紧支与局部有限使相关和有限 |
| Stokes局部式 | 全空间逐坐标积分为零；半空间最后方向给负的边界迹，外积顺序与边界定向相乘恰好同号；明确核查n=1 |
| Stokes拼接 | 对每个ρᵢω应用单卡公式后再相加；dρᵢ∧ω余项只在求和后消失，不在单项中删去；边界拉回支集紧 |
| 应用与边界 | 推导Green、通量/散度形式、紧无边流形的恰当顶次形式积分为零；给出仅dω紧支仍失败的半直线反例 |
| 习题 | 8题均有解答，覆盖截断、球坐标Jacobi、Möbius定向、区间/圆环符号、Green、球面通量、无穷远项及全局原形式障碍 |

依赖链：第4章局部截断与切空间、第6章外代数、第7章外微分及自然性 → 紧耗尽与单位分解 → 定向与单卡积分 → 全局积分 → 半空间Stokes及拼接。采用欧氏多重积分换元、Fubini及一维微积分基本定理为本科先修；没有借用尚待建立的联络、度规体积、Hodge星、上同调、领圈或加倍流形。

带边单位分解在相对半球上限制欧氏截断来构造；支集按相对拓扑理解。半空间中的单卡形式只在坐标域之外、仍在半空间内延零，不误要求跨越真实边界的延零光滑。紧支Stokes要求原形式紧支，仅外微分紧支不够。
