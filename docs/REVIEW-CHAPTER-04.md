## 内容与作者自查

以下为本轮写作者自查，不是不同审阅者进行的独立数学审阅，也不是形式化验证。

| 主线 | 本轮完成及自查重点 |
|---|---|
| 曲线模型 | 检查速度等价关系的换卡不变性，以坐标直线实现任意分量，并证明线性结构不依赖选卡；允许零速度曲线 |
| 函数芽与导子 | 区分局部坐标函数与全局函数；显式构造紧支截断，补证全局导子的局部性及局部函数芽的全局代表，未提前使用单位分解 |
| 坐标张成 | 通过沿线段积分的一阶余项分解证明导子由 `D(x^i)` 决定；解释参数积分的光滑性，不把参考书外引的张成步骤当成已在原书证明 |
| 余切与换卡 | 用对偶定义余切空间；证明坐标微分是对偶基；分量变换使用向量的Jacobi矩阵与协向量的逆转置，并以配对不变核查 |
| 切映射与拉回 | 从复合曲线定义切映射，证明良定义、线性、矩阵表达和链式法则；函数拉回、逐点协向量拉回分别标注定义域 |
| 局部与全局 | 微分同胚蕴含切映射可逆；同维情况下单点可逆只推出局部反解；用周期映射与立方映射核查反例 |
| 丛构造 | 给出切丛、余切丛的拓扑与光滑图册、线性过渡；分别证明Hausdorff性、第二可数性及局部平凡性，未把局部乘积误写为全局乘积 |
| 截面 | 证明光滑分量判别、总切映射光滑与一形式拉回光滑；指出一般映射不能自动推前一个向量场 |
| 习题 | 4.1–4.4为梁书文内命题的练习化或扩展，4.5–4.8原创；均有对应解答，包含计算、证明、概念与反例 |
