## 几何与来源自查

这是写作者的几何和版面自查，不是独立数学审阅。

| 图 | 检查重点 |
|---|---|
| 子空间开弧 | 圆周与开圆盘的交，空心端点不属于交集；继续保留梁书图1-4及双页码 |
| 有限子覆盖 | 只画选出的有限子族，三个开区间覆盖整个闭区间，不拿图形代替紧致性证明 |
| 隐函数图像 | 单位圆顶点满足F_y=2，只在所选邻域画上半圆解，不暗示整圆是单值函数图像 |
| 外积面积 | 两向量线性无关且行列式为正，次序与图注的正定向一致 |
| 密切圆 | 抛物线y=κx²/2在原点的曲率为正κ，圆心(0,1/κ)、半径1/κ，不把相切当成整条曲线相同 |
| 参数曲面 | 使用解析抛物面和固定线性斜投影，原点切向量按(1,0,0)、(0,1,0)绘制，法向为(0,0,1)，图注说明投影夹角不代表真实夹角 |
| 换卡图 | 两张卡定义域限制到交集，过渡箭头为ψ∘φ⁻¹，不依赖环境空间嵌入 |
| 同速曲线 | 两条曲线均使用参数t，原点速度相同；图注区分曲线像相切与参数速度相同 |
| 切映射 | F(x,y)=(x,y+x²)在(1,0)将速度(1,0)送到(1,2)，不同比例在图注说明 |
| 极坐标基 | 坐标向量的长度及方向随半径、角度重新计算；单位角向量单独表示，PGF度数参数不改变数学导数的弧度约定 |
| 局部切丛 | 基点、纤维、零截面与一般截面分别标示，只画一维局部模型，不推出全局平凡性 |

TikZ.net页面实际核对了Efraín Soto Apolinar的密切圆、Izaak Neutelings的三维坐标和Jake的平滑曲线示例。参考构图及通用画法后按正文公式重新编写；来源、作者、链接及未复制外部代码的边界见 `course-study/figures/SOURCES.md`。既有改绘来源没有改写为原创；新增图没有赋予虚构的原书图号。
