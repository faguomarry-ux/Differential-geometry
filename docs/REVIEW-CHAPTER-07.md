## 数学主线及依赖自查

| 主线 | 本轮完成与核查重点 |
|---|---|
| 局部表示 | 形式为外幂余切丛的光滑截面；递增求和不加阶乘，全有序指标求和含1/k!；按求值推导换卡及局部拼接 |
| 曲线积分 | 用逐点一形式求值和一维积分定义，证明重参数化及全微分的端点公式；不借尚未建立的Stokes定理 |
| 外微分 | 先在坐标块按系数定义，证明平方零与带符号乘法式，再用d(dy)=0证明换卡相容；唯一性针对与限制相容的运算族，不把局部坐标函数强作全局函数 |
| 无坐标公式 | 核对删去槽位和括号置于首槽的符号；说明函数系数导数由括号项抵消，再在坐标标架检验；非坐标余标架的dθ项不可省略 |
| 拉回 | 用切映射定义协变拉回，证明与外积、反向复合及d相容；明确不要求光滑映射可逆或处处满秩 |
| Lie与Cartan | Lie导数按流的拉回在零时求导；证明局部生成规则，并通过两种带符号导子的交叉项相消建立Cartan公式，不要求流完备 |
| 交换关系 | 证明Lie导数的求值式、与d交换、与内插的交换子及两Lie导数的交换子；与第5章[X,Y]=XY−YX的符号一致 |
| 同伦算子 | 将时间因子放在最前：H*ω=dt∧α+β；明确参数积分光滑性、d与积分交换和端点差，得到dK+Kd=H1*−H0* |
| 径向原形式 | H(t,x)=a+t(x−a)，时间方向为x−a，空间输入为tv，故权重为t^(k−1)；单列k=1端点及零次公式，未使用t的负幂 |
| 局部/全局 | 星形域和局部坐标球中的正次数闭形式恰当；零次仅局部常值；角形式用一维闭曲线积分阻止全局原函数，不误套穿过删点的径向同伦 |
| 习题 | 8题全部有解答；三道梁书原题改述/扩展与五道原创题分开，覆盖分量、标架、退化拉回、Cartan符号、同伦余项和全局反例 |

依赖顺序：第4、6章的余切与外代数 → 坐标外微分 → 拉回自然性 → 第5章局部流给Lie导数 → Cartan → 同伦分解 → Poincare局部引理。没有以待证的Stokes、de Rham上同调、光滑逼近或单位分解补足关键步骤。

同伦H定义在[0,1]×M的某个开邻域，不要求所有基点共用同一时间延长区间。对星形开集U，集合{(t,x):x∈U，a+t(x−a)∈U}就是所需开邻域。逐点缩小基空间邻域并利用紧时间段，足以保证参数积分光滑。这避免对一般星形域暗加统一延长假设。
