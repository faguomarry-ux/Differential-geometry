## 数学主线、假设与证明边界

| 项目 | 本章自查 |
|---|---|
| Clifford构造 | 实正定负平方vw+wv=−2g(v,w)；张量商给泛性质，外代数楔乘减内乘作用在真空证明有序基独立，不预设商维数或V单射 |
| 分次与对合 | 奇偶分次/长度滤过，伴随分次与外代数同构；反对称化是向量空间同构。反序τ(v)=v、实Clifford共轭bar(v)=−v，与复系数共轭分开 |
| 复表示 | 在Λ*C^m上以ε−ι、i(ε+ι)构造生成元；真空投影和矩阵单位证明偶维满矩阵代数，中心幂等元分出奇维两个块；未采用实八周期分类 |
| 手征与不可约 | Γ=i^m c1…c2m在Fock基等于(−1)^deg；奇维两个扩展限制到偶代数同构。Spin张成偶子代数，半旋量不可约；全偶维旋量限制Spin已可约 |
| 反射及覆盖 | 正定归纳证明至多n反射；单位向量扭伴随是超平面反射，偶乘积用普通共轭。偶中心化子只有标量，范数1迫使核±1 |
| Lie结构 | 用共轭保持V和bar(a)a=1的闭集合刻画Spin，调用第15章已证闭子群定理；双向量微分给so(n)，逆函数定理及两点纤维证明二重覆盖，不预引全局单连通性 |
| 半角及Spin3 | eiej/2映为ei→ej的旋转生成元；2π提升−1。三维偶代数四元数与简单双向量给Spin3=S3，题解另给SU2矩阵实现 |
| Spin结构 | 必须带与SO标架丛的相容映射Φ，等价须保持Φ；一个过渡矩阵可提升不等于过渡函数可单值提升，更不等于三重相容 |
| 障碍与分类 | 在给定可缩有限交集的标架覆盖上直接证明zijk为中心符号二上闭链，选择改变为上边界；类零当且仅当可拼接，存在时结构为Cech H1挠子。良覆盖存在、Cech/奇异比较及w2识别明确未证 |
| 球面与圆周 | Spin(n+1)→Sn的稳定子是Spin(n)，映到外向法向在首的切标架；球面spin不等于切丛平凡。圆周边界的转动标架提升给反周期结构 |
| 旋量联络 | 相伴关系沿用第16章右作用；A^S=Σg(∇ei,ej)ci cj/4，转置后不能不改号。主联络拉回再用λ*逆；用双向量交换子证明度量及Clifford相容，曲率同样提升 |
| Dirac符号 | D=Σci∇ei；[D,f]=c(grad f)。以∂→iξ取符号时σ=i c(ξ#)，平方正|ξ|²；不用i的符号约定不能混写 |
| 自伴与分析 | 散度证明紧支形式自伴；未据此声称非紧本质自伴、谱完备、Fredholm或APS边界理论。偶维D交换手征分量 |
| 完整平方缩并 | 正规标架给D²=∇*∇+Σi<j ci cjR^Sij；四重指标曲率项中，共一指标由对换对称抵消，四互异由Bianchi抵消，仅两不同指标给Scal/4；球面为正的曲率号一致 |
| 消失结论 | 紧致、连通、无边界且Scal≥0时调和旋量平行，某点Scal>0使核零；不连通逐分支。非紧/带边不能直接丢弃积分边界项 |
| 环面与扭丛 | 平坦环面用中心符号条件构造结构，拉回可缩Rn后以格特征证明2^n个结构穷尽且互异；给显式频率模式，核由平行性算出，不依赖一般谱完备。扭平方另加Σi<j ci cjF^Eij，不假定有符号 |
| 校准比较 | 闭性及逐有向规范平面上界1；对给定光滑配边用Stokes证明全局比较，对局部紧支变分用Cartan和坐标球域Stokes得极小；一般同调/积分流另列范围 |
| Wirtinger与相位 | 投影J的斜标准形给ω^k/k!不等式及等号平面；特殊Lagrange用复Hadamard及等号证明。图像定向须Im det=0且Re det>0，三维sqrt3 I给反分支反例 |
| 旋量到校准 | 平行旋量双线性张量逐项求导给平行闭形式，但可能为零且未核定逐平面界；未假装自动得到G2/Spin7校准或holonomy分类 |

依赖链：第6–7章张量/外代数 → Clifford基与复表示 → 第15章闭子群/覆盖 → Spin双覆盖 → 第16章主丛及相伴 → 第11章Levi–Civita/曲率与第8章积分 → 旋量联络、Dirac及平方 → 未扭消失/扭曲率和校准实例。没有先调用第20章指标定理。
