## 数学主线与依赖自查

| 主线 | 本轮内容及检查要点 |
|---|---|
| 子流形 | 从第1章常秩定理推出浸入、浸没正规形；嵌入必须为到子空间像的同胚；证明嵌入像的子流形性质时显式排除其他像分支 |
| 正则值 | 明确空原像约定；非空纤维维数为源维数减目标维数；用包含映射微分识别切空间与核；以球面和正交矩阵检验值域选择 |
| 拓扑反例 | 自交浸入不单射；无理绕行以抽屉原理给出返回序列，证明单射浸入的逆仍可不连续；紧源命题保留单射假设 |
| ODE | 补证积分不等式；在一致范数路径空间中证明完备性并作压缩迭代；用差估计、Taylor余项与线性变分积分方程证明有限维初值/参数光滑依赖；非自治方程通过增添时间变量处理 |
| 局部流 | 由唯一性拼成含零极大开区间；用有限次局部解复合证明总定义域开且解映射光滑；说明时间片的逆、区间平移关系与复合的定义域条件 |
| 完备性与流盒 | 有限覆盖给统一短时间，排除紧无边界流形上的有限极大端点；由横截片及逆映射定理构造流盒，保留非零点假设 |
| 李括号 | 展开并抵消二阶项，证明光滑性、Leibniz公式、Jacobi及相关性；区分实双线性与函数双线性，以及点向量和邻域向量场 |
| 流交换 | 拉回到固定切空间后导数为正号的括号，固定目标点的推前为负号；用保持性和ODE唯一性证明括号为零当且仅当局部流交换 |
| Frobenius | 先用可逆小行列式将标架前k个分量归一化，再利用对合性证明新标架两两交换；由交换流和横截片构造坐标；分别证明逆命题、第一积分及积分片的局部唯一性 |
| 习题 | 8题均有解答；5.3、5.4为梁书文内主题的改编/扩展，其余6题原创；兼具概念、计算、完整证明与反例，不用习题替代正文核心证明 |

依赖顺序：欧氏常秩与逆映射 → 子流形；路径空间压缩迭代 → ODE光滑依赖 → 极大局部流与流盒 → 括号与流交换 → Frobenius局部坐标。未提前使用单位分解、外微分、一般向量丛理论或后续Frobenius结论证明ODE工具。

## 图示与几何核查

本轮新增3图，沿用 `DGDiagram`、既有语义样式及分组隔离接口，集中于 `modules/manifolds-tangent.tex`；现共18个命名图、3组模块。

| 图名 | 解析模型与检查 |
|---|---|
| `flow-box` | X=∂x+x∂y，解为 y=z+x²/2；坐标(s,z)=(x,y−x²/2)拉直；说明光滑换坐标不等距 |
| `bracket-loop` | X=∂x，Y=∂y+x∂z，从原点按X、Y、−X、−Y四段运动；s=t=1时终点(0,0,1)，剩余方向与[X,Y]=∂z一致 |
| `integral-plaques` | z−xy=c，c=−1.8、0、1.8，|x|、|y|≤0.75；拉直到w=c；选择投影使每片的投影Jacobi行列式至少0.184375，避免网格折叠，并移动底部标签防止压线 |

三图均为本工程原创解析示意，无原书图号；图注列出方向、比例或斜投影以及局部适用范围。图目录中的数学公式使用TeX，修复了直接使用Unicode偏导符号造成的字体缺字。独立图册包含18个默认图及5个既有参数变体，共23页；参数隔离断言通过。
