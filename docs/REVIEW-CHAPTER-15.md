## 数学依赖与逐项自查

| 项目 | 本轮核查 |
|---|---|
| 定义与矩阵例子 | 光滑实李群有限维、Hausdorff、第二可数、无边界；不默认连通。SL的行列式导数、O的对称矩阵值导数满射，先独立证明具体嵌入结构 |
| 李代数与符号 | 左不变场取单位元值，括号继承第5章；矩阵括号XY-YX。取逆推前给右不变场反号；左不变场的流为右平移g exp(tX) |
| 指数的存在和光滑 | 用统一短时间解左移延拓建立完备及一参数式，再把任意参数的时间1解写成短时间参数解的有限乘积；不从局部可逆推全局满射 |
| 同态与覆盖 | 微分保持括号、指数自然性、常秩核；连通群由单位邻域生成给微分刚性；给出核平移片的不交原像证明覆盖，而非只说局部可逆 |
| Ad、结构方程 | 使用第5章流拉回的正号推出ad_XY=[X,Y]；左Maurer–Cartan取g^-1 dg，括号楔积约定明确2因子 |
| Killing | 迹及Jacobi证明自同构不变/无穷小不变、根空间为理想；so(3)负定、sl(2,R)不定、交换代数零。未预用Cartan判据或结构分类 |
| 紧群平均 | 左不变正密度的右移系数为R_>0连续特征，紧性迫使为1；归一化后平均。仅证明所需紧Lie群版本，不引一般Haar定理 |
| 双不变曲率 | Koszul给∇XY=[X,Y]/2，曲率为-[[X,Y],Z]/4，Ric=-B/4；本书截面曲率号为正球面。非双不变惯量例子独立由Koszul重算 |
| 闭子群 | 先取H内C¹曲线速度空间，乘积/重参数给线性；log曲线的整数幂及闭性给exp(tX)∈H。归一化log极限排除补空间的小非零方向，乘积指数坐标得到嵌入结构 |
| 商流形 | 用左陪集gH（即右乘H轨道）。闭性给Hausdorff，开商映射给第二可数；切片比较先固定大坐标盒再缩小横截面，局部截面给过渡光滑和下沉性 |
| 作用与齐性 | 正指数左作用基本场是李代数反同态，稳定子闭；轨道映射常秩。满射常秩引理用可数紧覆盖和嵌套球证明满秩，避免隐藏调用Sard定理 |
| 不变度量 | 切空间g/h上的Ad(H)不变正定内积与G不变度量对应；紧稳定子平均得到存在。球面和Grassmann稳定子、图坐标分别计算 |
| 对称空间 | 等距由一点及微分确定；全局反射延长测地线并给抽象等距群传递；五阶协变张量的奇性给∇R=0。不以此声称全体等距群已是Lie群 |
| 局部判别 | ∇R=0时平行标架中的Jacobi方程为常系数，幂级数S(K_v)给指数拉回度量的偶性，因此反射局部等距；不无条件推广为全局对称 |

证明链：第5章ODE/常秩/括号 → 左不变完备场与指数 → Ad及同态 → 闭性与指数坐标 → 闭子群/商流形 → 齐性空间。第8章紧区域密度积分 → 紧群平均 → 不变内积；第11章Koszul和第12章Jacobi → 双不变曲率与局部对称判别。链中没有循环使用尚未证明的Lie第三定理或全体等距群结构。
