## 数学主线、符号及证明边界

| 项目 | 本轮逐项核查 |
|---|---|
| 拉回与同态 | 以局部乘积构造f*F，核对其集合/子空间拓扑及普遍分解；不要求f浸入。df的同底目标为f*TN，不把拉回丛所有截面误认成原截面拉回 |
| 分裂和商丛 | 单位分解给纤维内积，正交补标架给商丛和短正合列分裂；结构不依赖内积而具体分裂依赖选择 |
| 主丛拼接 | 右G作用，s_j=s_i g_ij，h_i=g_ij h_j，g_ik=g_ij g_jk；逐块证明商Hausdorff、第二可数及局部平凡化。一般自由适当作用商定理不作为隐含先修 |
| 标架与相伴 | Fr(E)取u:K^r→E_x，右作用u∘g。相伴关系[pg,v]=[p,ρ(g)v]，等变函数f(pg)=ρ(g)^-1f(p)；与第6章坐标过渡及第10章换标架对齐 |
| 形式下降 | 水平性消去提升差，等变性消去纤维代表差，得到相伴丛值形式；一般非平凡表示时不把它说成底空间固定V值形式 |
| 基本场号 | 右作用正指数ξ#(p)=d/dt p exp(tξ)，在纤维内为左不变场，故括号同态；右移生成元变为Ad(g^-1)ξ。与第15章左作用反同态明确区分 |
| 联络公理 | 再现竖直生成元及R_g*ω=Ad(g^-1)ω等价于右不变水平补分布，不引入未经选定的正交性 |
| 局部势/存在 | ω=Ad(h^-1)A+h^-1dh，变截面A'=Ad(g^-1)A+g^-1dg；局部连接形式按底空间单位分解加权，保留再现及等变，G无须紧致；差下降为Ω¹(M;AdP) |
| 水平提升 | 方程h'=-dR_h A(γ')，矩阵即h'=-A(γ')h。用紧时间上的系数界给单位元附近统一δ，再由右平移搬到任意初值，证明整段路径提升存在，避免非紧群逃逸的隐含漏洞 |
| 曲率/括号 | Ω=dω+[ω,ω]/2水平等变；Cartan公式使竖直收缩的两项抵消。水平括号缺陷为-Ω#，相伴曲率为ρ_*(F)，与第10章R及矩阵Ω号一致 |
| 协变外微分 | 对水平等变形式D=d+ρ_*(ω)∧仍水平等变，平方为ρ_*(Ω)∧；伴随表示用带次数Jacobi证明Bianchi，不默认每个李代数已有忠实矩阵表示 |
| 标架对应/局部平坦 | 由换标架律重建标架主联络；度量相容对应o(r)/u(r)值势。Ω=0经Frobenius给局部水平截面，过渡局部常值，不擅自推全局水平截面或所有闭路移动恒等 |
| 规范变换 | Φ(p)=pu(p)，u(pg)=g^-1u(p)g；本书取Φ*ω，按复合为右作用。区分主动拉回与被动换截面，相伴联络T_Φ^-1∇T_Φ，闭路元素共轭变换 |
| Hopf底空间 | 用两实二维卡构造CP¹并显式识别单位S²，不预用第17章复流形理论。w=z1/z0，s1=s0 exp(-iφ)，球面外向与w卡正向一致 |
| Hopf曲率/非平凡 | ω=Σbar(z_j)dz_j再现iR，局部势含归一化分母导数，F=i vol/2，周期∫F/(2πi)=1。Stokes排除全局截面；标准表示相伴丛识别为重言线丛，归一化无零截面亦排除 |
| 周期符号/全局反例 | 酉Chern形式iF/(2π)在该模型积分-1，不与1/(2πi)混同。两个圆盘径向移动给截面，赤道相位提升证明圆群周期整数，未声称一般分类。Möbius离散holonomy及平坦圆周区分平凡/平坦/全局水平截面 |

依赖链为：第6章拼接与第8章单位分解 → 拉回/商丛/主丛/相伴 → 第15章李群/表示/基本场 → 主联络及水平ODE → 形式下降/曲率/Bianchi/第5章Frobenius的局部平坦 → Hopf及圆周实例。非平凡性只用第8章Stokes，整数周期只再用区间上的相位ODE；没有循环调用第18章一般Chern类或第20章规范场理论。
