## 正文与证明自查

| 主线 | 本轮完成及自查重点 |
|---|---|
| 张量积 | 从形式基自由空间模双线性关系构造，证明泛性质、保持标准映射的唯一同构、张量积基与维数；明确纯张量张成不等于每个张量都是纯张量 |
| 诱导映射 | 用泛性质构造映射的张量积、结合/交换及标量同构；给出有限维双对偶、线性算子与对偶张量的自然识别，不误推广到任意无限维空间 |
| 型别与换基 | 采用 T^r_s=V的r次张量幂与V*的s次张量幂之积；上槽输入协向量，下槽输入向量；从求值展开推导分量变换，区分一般换基P与坐标Jacobi矩阵J |
| 缩并与升降指标 | 用向量—协向量配对及泛性质定义缩并；求和公式与无坐标定义相容；同型指标不能无条件相加，升降指标另需非退化双线性形式 |
| 外代数 | 以v⊗v生成的双边理想作商，证明递增外积基、维数、交替泛性质与分次交换律；用行列式泛函证明基的独立性 |
| 归一化 | 对称化/交替化均含1/k!；外积按完整行列式识别，与第1章1/(p!q!)全排列和一致；明确一次外积为两项之差而非其一半 |
| 外代数运算 | 证明拉回保持外积、内插平方为零与带符号乘法式；用四维二形式平方非零区分奇次/偶次及可分解性 |
| 向量丛 | 明确纤维坐标方向vβ=gβαvα，构造商拓扑并证明局部块开、Hausdorff性、第二可数性及光滑性；证明截面相容、换平凡化与全局标架判别 |
| 丛的代数运算 | 对偶用逆转置，直和用块矩阵，张量积逐因子变换，外幂用小行列式；验证光滑性与相容条件；建立张量场、形式、拉回丛的逐点含义 |
| 常秩子丛 | 用光滑可逆子块给出显式左右消元矩阵，证明核/像有局部标架；跳秩例子保留为反例，不把点态线性子空间直接称为子丛 |
| 习题 | 8题全部配解答；3道梁书原题改述与5道原创题分开登记，覆盖泛性质、缩并、度规、外积、拉回、非平凡性和跳秩 |

依赖从第1章有限维对偶/行列式和第4章切丛/余切丛出发；拼接构造的第二可数性仅用可数基与可数子覆盖。Möbius线丛无全局非零截面的证明只用反周期系数与中间值定理，不提前使用单位分解、特征类或联络。常秩丛映射的证明为线性代数中的光滑块消元，不依赖后续一般丛理论。
