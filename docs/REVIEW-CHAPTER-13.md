## 数学主线与条件核查

| 主线 | 本轮核查 |
|---|---|
| 沿浸入求导 | 在拉回环境切丛定义联络，允许自交像；正交投影由Gram逆矩阵光滑构造，不在自交像上假定单值场延拓 |
| 法丛与第二基本形式 | B是法丛值对称二次协变张量；诱导切联络由无挠/相容识别为Levi–Civita，法联络相容；A与B的配对固定Weingarten负号 |
| 全测地/平均曲率 | 用测地初值和极化证明B=0判据；H向量取trace(B)/m，球面外法向为-n/a，与第2章S=-dn、H=trace(S)/2一致 |
| 相容方程 | 分别展开环境曲率作用于切、法场，保留一般环境曲率项；Ricci法曲率为环境项加[Aξ,Aη]配对，未与Ricci张量混淆 |
| 缩并与法平坦 | 从Gauss式得到Ricci/标量；欧氏极小Ric≤0不误作所有截面非正；法平坦与形算子逐点交换等价，不保证全局光滑共同主标架 |
| 全脐分类 | 明确m≥2、局部法向和连通；由Codazzi得λ恒定，再证明球/平面局部开集，不凭局部条件断言全局球面 |
| 活动标架 | 列指标表示被求导基向量；混合块为β和-β转置；从既定dω+ω∧ω计算三块；给出解无挠/斜对称方程的唯一性代数证明 |
| 局部基本定理 | 在TM⊕E构造相容联络D，三组方程给D平坦；局部平行平凡化使solder一形式闭，再逐分量Poincare积分；证明浸入、法数据实现及刚体运动唯一性 |
| 全局边界 | 圆周B=0实例给闭而不恰当的重建形式；局部相容不足以保证全局单值、嵌入、无绕行或完备 |
| 体积第一变分 | 从变分度量及行列式微分推导，保留切散度与边界外余法向项；紧支法向场由环境局部指数实现，无须环境完备 |
| 定向边界 | 以绝对Jacobian说明紧区域体积密度；不要求全局定向，不宣称已发展一般密度丛理论 |
| 极小与最小 | H=0为驻定，ΔF=mH与Laplace约定一致；紧致无边界欧氏极小浸入不存在；另以面积被积函数严格凸性证明固定边值图像类中的最小性 |

依赖顺序为：第5章局部浸入/ODE、第6章子丛、第10–11章联络/曲率/Levi–Civita → 正交分解 → 三组方程 → 适配结构方程 → 平坦联络和第7章Poincare引理重建；体积变分另用第8章Stokes、第11章散度/行列式及第12章局部指数。不先借用全局子流形定理、极小第二变分或椭圆PDE存在理论。
